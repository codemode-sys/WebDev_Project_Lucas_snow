SNOW TRAILS — STUDENT WEBSITE

Open index.html in a browser. Keep the css and images folders beside the HTML files.

Files: index.html, about.html, destinations.html, css/style.css, images/mountains.svg.

Scope: Three-page fictional travel-agency prototype based on Lucas Snow's client brief. The third page resolves the client's request for three pages, although the Week 3 lab requires only two.

Features: Shared navigation, distinct page layouts, external stylesheet, class and attribute selectors, hover and keyboard focus states, CSS background image, explicit height/width via box sizing and card styling, padding, margin and borders. Google Fonts with local fallback. Original decorative SVG illustration; no third-party image attribution needed.

Accessibility: Skip link, semantic landmarks, one primary heading per page, hierarchical headings, current-page navigation, visible keyboard focus, responsive layout, readable text, no flashing animation, reduced-motion preference. Background illustration is decorative and conveys no required information.

Test before submission: Open all pages, follow every navigation link, use Tab and Enter without a mouse, zoom to 200%, and test a narrow viewport. Deploy your own repository through GitHub Pages and run Lighthouse on every page. Save the real reports/screenshots requested in Week 8. No Lighthouse audit or deployment has been performed for this download.

Publishing: Upload the extracted project contents to your public repository, keeping index.html at the root. In repository Settings > Pages, choose deployment from a branch, select your branch and root folder, then save. Confirm the published site works.

Replace sample trip copy and fictional story with your own approved content. Review and understand the code before your TA demo. This project does not accept bookings. Google Fonts requires an internet connection; fallback fonts work offline.
